# Changelog

## 1.2.10 (2026-10-04)

- Show live Codex activity in the macOS menu-bar panel: working conversations, active helper agents, and conversations waiting for a reply or approval.
- Refresh counts every three seconds while the panel is visible. Idle conversations are excluded, and an unavailable service is reported explicitly.
- Read activity from the existing local Codex service without starting conversations or reading their message history.

Live Codex activity is currently unavailable on Windows and does not include separately hosted Codex processes.
