# AgentHarbor Documentation

User and contributor docs for AgentHarbor — a macOS desktop app for managing AI coding-agent configurations across Claude Code, Cursor, Codex, Gemini CLI, and Windsurf.

## Guides

- **[Getting Started](./getting-started.md)** — install the signed DMG, sign in to providers, and connect your first project.
- **[Analytics & Tray](./analytics.md)** — what the menu-bar icon, popover and per-provider analytics pages show, and how limit-state warnings work.
- **[Deploying Capabilities & Agents](./deploying-capabilities.md)** — the deploy wizard, presets, drift detection, and undo.
- **[Dan Features & Benchmarking Roadmap](./dan_features.md)** — research-backed roadmap for multi-model comparison, benchmark lab, and provider expansion.
- **[Dan Features (Claude edition)](./dan_features-claude.md)** — deeper companion with codebase audit, 2025–2026 eval landscape, concrete Benchmark Lab architecture, and a short-duration feature backlog.
- **[Build & Release](./build-and-release.md)** — local dev build, signed/notarized release build, and publishing a GitHub release.
- **[Troubleshooting](./troubleshooting.md)** — common errors (Gatekeeper, expired tokens, rate limits, notarization).
- **[Regression Checklist](./regression-checklist.md)** — manual QA matrix used before releases.
